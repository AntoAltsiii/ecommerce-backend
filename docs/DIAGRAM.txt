╔════════════════════════════════════════════════════════════════════════════════════════════════╗
║                                    STACK TECNOLÓGICO                                           ║
╚════════════════════════════════════════════════════════════════════════════════════════════════╝

  🔹 Backend Framework:     Java 17 + Spring Boot 3.2.0
  🔹 API Gateway:           Spring Cloud Gateway (WebFlux Reactive)
  🔹 Identity & Access:     Keycloak 23.0 (OAuth2 + PKCE + JWT)
  🔹 Microservices:         2 servicios independientes (Producto, Compra)
  🔹 Persistence:           PostgreSQL + Spring Data JPA + Hibernate
  🔹 Containerization:      Docker + Docker Compose
  🔹 Security:              OAuth2 Resource Server, Role-based access (ADMIN, USER)
  🔹 Inter-service Comm:    RestClient (síncrono)
  🔹 External Integration:  WebClient (Open-Meteo Weather API)


╔════════════════════════════════════════════════════════════════════════════════════════════════╗
║                                FLUJO DE AUTENTICACIÓN                                          ║
╚════════════════════════════════════════════════════════════════════════════════════════════════╝

  1️⃣  Usuario → Gateway (http://localhost:8090)
      │
      └──► Login Request con PKCE S256

  2️⃣  Gateway → Keycloak
      │
      └──► OAuth2 Authorization Redirect

  3️⃣  Keycloak → Gateway
      │
      └──► JWT Token (con roles: ADMIN, USER)

  4️⃣  Gateway → Microservicios
      │
      └──► Authenticated Requests con Bearer Token

  5️⃣  Microservicios → PostgreSQL
      │
      └──► CRUD operations con JPA/Hibernate
